# --- Wake word (Fase 3) — nada a instalar no runtime ---
# A escuta pela palavra "Oráculo" (core/wake.py) roda no onnxruntime declarado
# abaixo, com três modelos pequenos: dois de característica do openWakeWord
# (melspectrogram + embedding, 2,4 MB somados, Apache-2.0) e a cabeça treinada
# aqui mesmo. Os dois primeiros são baixados UMA vez pelo treinador; a cabeça sai
# de tools/treinar_wake.py. Nada disso acontece no caminho da conversa.
#
# O pacote `openwakeword` foi descartado de propósito: não instala no Python 3.14
# deste venv (arrasta tflite-runtime) e o que ele faz é justamente a cadeia que o
# core/wake.py implementa em ~40 linhas.
#
# scikit-learn é dependência SÓ do treinador — como o pyte é só do teste. O
# runtime não importa sklearn: a cabeça é um .npz lido com numpy.
#   .venv/bin/python -m pip install scikit-learn   # só para treinar

# --- STT alternativo: Parakeet V3 (onnx-asr, CPU rápida) ---
# Motor opcional selecionável via config.STT_ENGINE = "parakeet". Coexiste com o
# faster-whisper. onnxruntime = CPU; o modelo ONNX é baixado do HF na 1ª execução.
# Limite de ~20-30s por clipe: irrelevante na conversa (o VAD recorta a fala e
# VAD_MAX_SECONDS a limita), mas ainda vale para /transcrever de arquivo longo.
onnx-asr
onnxruntime
